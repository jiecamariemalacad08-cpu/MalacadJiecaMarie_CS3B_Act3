 📌 Project Description

This project is a *web-based AI application* built using Streamlit that performs *real-time object detection and tracking* through a webcam.

It uses the powerful YOLOv8 model to identify everyday objects such as:

- Person  
- Cell phone  
- Bottle  
- Chair  
- Laptop
- Cup

Detected objects are displayed with:

- 📦 Bounding boxes  
- 🏷 Labels  
- 🔢 Object counting  
- ⚡ Real-time tracking  

---

 🚀 Features

 ✅ Core Features (80%)

- Live webcam stream in browser  
- Real-time object detection  
- Bounding box visualization  
- Object labeling  
- Smooth tracking across frames  

---

 🌟 Enhancements (20%)

- 🔢 Object counting (user-selected object)  
- ⚠ Alert system (e.g., cell phone detection, crowd alert)  
- 💾 Save detected frames as images  
- 📝 Detection logging (CSV file)  
- 🎞 Video recording of detection  
- 📊 FPS (performance monitoring)
